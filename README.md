# Ayoade Adebayo — Product Designer

A responsive personal portfolio featuring selected product design work and the Brainbud case study.

## Run locally

Open `index.html` in a browser. The Brainbud case study is available from the featured project card.

## Project files

- `index.html` — portfolio homepage
- `brainbud.html` — Brainbud case study
- `styles.css` — shared responsive styles
- `script.js` — navigation, contact form, and image viewer interactions
- `My brainBud (1)/` and `61shots_so.png` — project imagery
